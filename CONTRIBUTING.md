# Como contribuir

Obrigado por querer contribuir!

Passos básicos:
1. Faça um fork do repositório.
2. Crie uma branch: `git checkout -b feat/minha-feature`
3. Faça commits claros e atômicos.
4. Abra um Pull Request para `dev` com descrição das mudanças.

Antes de enviar PR:
- Rode o linter: `npm run lint`
- Rode os testes: `npm test`
- Verifique o build: `npm run build`

Guidelines:
- Siga o estilo existente do código.
- Adicione testes ao implementar novas features.
- Para bugs graves, abra uma issue primeiro descrevendo como reproduzir.
